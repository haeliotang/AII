# M2 运行时间基线（2026-10-31）

**用途**：M2 退出条件要求"求解器在 Base-01 全部用例上的运行时间被记录（作为后续规模化的基准，不设阈值）"。本文件是该基线；它不用于判定任何用例通过与否，也不设性能门槛。

## 环境与方法

- 机器：Apple M1 Pro（arm64），macOS
- 工具链：`rustc 1.94.0 (4a4ef493e 2026-03-02)`
- 构建：`cargo build --release --locked -p poie-ontology`
- 命令：`./target/release/poie-graph scenarios/base-01/cases.toml --timings`
- 计时口径：每个用例的 `solve time` 由 `Scenario::run` 包裹，包含补丁应用与模型重新校验；S21–S24 的预登记断言会额外触发候选路线枚举或外部依赖上溯，因此明显慢于其余用例（单次 `solve` 本身仍在亚毫秒级）。
- 测量点：M2 退出复核分支（契约升为 v0.2-draft 的同一次变更）。

## 说明与后续

- 这些数值只代表当前小规模合成模型（13 个资源、9 个资产、6 个工艺、25 个用例）。M3 将把它作为规模化前的对照，不构成对更大模型的性能承诺。
- 若后续用例数或模型规模增长，应在同一命令下重新记录，并在 `experiments/` 中附复现清单；不得用本基线的绝对数字比较不同机器。
- 复现：检出对应提交，执行上面的构建与命令；输出中的 `solve time` 行应可直接对照本表（允许机器差异）。
