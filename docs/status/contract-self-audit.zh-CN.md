# 契约自审与外部评审问题包（M1.8 支持材料）

本文件是**自审**，不是外部评审结果。目的：让 M1.8 的外部审读者不必从零开始——先看我们已承认的开放问题与实现限制，再直接针对可证伪的问题作答。使用方式：

1. 选一份契约与下面的一个问题；
2. 按"能否构造反例"审读，用 [contract-review 模板](../../.github/ISSUE_TEMPLATE/contract-review.yml) 登记（或直接引用本文件的编号）；
3. 维护者逐条给出 **接受 / 拒绝（附理由）/ 推迟（附重开条件）**（DEVELOPMENT M1.8）。

> 本文件中的"当前实现"指本仓库 `main` 上的参考实现与实验；它只用于说明契约的可实现性，不构成对契约的规范性补充。
>
> 另有 2026-11-01 的 AI 三方预演评审（[汇总](ai-preview/contract-review-summary.zh-CN.md)）：它不是外部评审，但列出了 25 项去重问题（13 项高严重度），可作为真人评审的对照起点；其中 P4/P5 已代码核对确认。

## 0. 自审结论摘要

- 三份契约均有可执行参考实现、预登记用例与报告；已知开放问题在各自 §8/§10 中列出，下方逐条转写。
- 已登记的实现级限制（不应被误读为契约已满足）：
  - **集合方法未实现**：`set_based`/`certificate` 推迟，见 [ADR-0004](../adr/0004-set-based-viability-scope.zh-CN.md)；
  - **数值失败**：参考实现没有迭代数值求解，`numerical_failure` 只在过程桥接/报告映射层出现；图谱求解只有 `candidate/blocked/search_limit/unknown`；
  - **H3/H4 物理部分未完成**：H3 为模拟执行，H4 只有 `modeled_gain`，设施未建造；
  - **M12.6 真实多节点未测**：只有进程内模拟与本机 TCP 双进程演示；
  - **M9.2 真实适配器未接**：只有模拟适配器与只读契约；
  - **标定缺失**：水模型为 `synthetic`，无现场数据。
- 结论：可作为 Foundation 门槛的外部评审输入；但 M1.8 的完成仍以"意见登记 + 逐条处置"为准，不能由自审替代。

## 4. 建议的评审顺序与重点

1. **SAP 生命周期与分区**（§3–§6、§11）：安全关键，优先确认"绝不重复物理动作/绝不双重所有权"的表述是否可判定；
2. **PO 求解规则**（§6.3 规则 9–15）：确认 blocked/search_limit/unknown 的区分不会被误用；
3. **VEC 指标与报告**（§4、§7）：确认截尾、目标集合与防作弊条款；
4. **PO 时间/能量/仿真**（§3.8–§3.10）：确认边界与未建模部分被明确标注。
