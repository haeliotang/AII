# ADR-0007：执行端幂等要求与降级方案（M10.1）

- 状态：提议（M10 开发中，待 M10 退出复核确认）
- 日期：2026-10-31
- 决策者：项目维护者（AI 代理起草，人类可推翻）
- 相关：[开发文档 M10](../DEVELOPMENT.zh-CN.md)、[SAP §4/§6](../../specifications/state-action-protocol.zh-CN.md)、[ADR-0005](0005-water-process-model.zh-CN.md)
- 取代/被取代：无

## 1. 背景

M10 允许 Poieweave 通过可写适配器发出有界动作。SAP 要求"同一幂等键最多派发一次"；但真实执行端能力不一：部分 PLC/机器人网关没有幂等键去重表，只有"命令 + 有效期"。

## 2. 评估

| 方案 | 风险 |
| --- | --- |
| 假设执行端去重 | 崩溃/ACK 丢失后重试可能造成重复物理动作（不可接受） |
| Poieweave 侧去重 | 只能防本进程重复；执行端内部重复/断电重启后仍可能重复 |
| 执行端幂等（要求适配器声明支持） | 需要网关能力；不支持时需降级 |
| 不支持幂等仍派发 | 违反安全底线 |

## 3. 决定

1. **可写适配器必须声明 `supports_idempotency`**；执行门在 `false` 时**拒绝派发**，返回 `Fallback`（现场原有控制逻辑接管），并记录原因。绝不盲派发。
2. 支持幂等的执行端必须对同一 `idempotency_key` 只执行一次；适配器兼容性测试需覆盖重复命令。
3. 命令必须带有效期；执行门检查 `valid_from/valid_until`，过期/未生效命令拒绝。
4. 执行端崩溃/断连后不自动重试：SAP 状态转 `outcome_unknown`，由人工核对（与 SAP §11 的 T9 风险一致）。
5. 人工接管与运行时降级优先于派发：接管期间只记录不派发；运行时降级回落到现场控制并记录。
6. 真实适配器（M9.2）需在 ADR 中记录是否满足幂等声明；不满足者不得进入有界执行。

## 4. 后果

- 不支持幂等的执行端只能用于只读影子运行，或必须先升级网关；
- 有界执行的"无重复物理动作"依赖执行端实现；Poieweave 侧不能单独保证，报告必须区分"协议侧重复"与"物理动作重复"；
- H3 实验需覆盖 ACK 丢失、崩溃、重启与重复投递，记录每次物理重复及其登记/修复情况。
