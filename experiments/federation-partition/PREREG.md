# M12.6 分区与重连实验登记（PREREG，模拟）

- 实验 ID：`federation-partition`
- 日期：2026-10-31
- 状态：**已登记，尚未运行**（本文件先于任何运行提交）
- 依据：[开发文档 M12](../../docs/DEVELOPMENT.zh-CN.md) · [ADR-0008](../../docs/adr/0008-federation-sync.zh-CN.md)

## 1. 问题

在进程内模拟的分区/重连中，跨站承诺是否保持可对账、是否**不出现静默的双重控制或超额预留**，冲突是否全部被报告且不被丢弃？

## 2. 场景（先于运行固定）

两场址 `site-a`、`site-b`，分区期间各自写日志/预留/租约，重连后双向交换并对账。可用批次 `lot-bronze` = 5 kg；时钟偏差界 2000 ms。

| 编号 | 场景 | 期望 |
| --- | --- | --- |
| P0 | 分区期间互不相干的工作，重连后交换 | 无冲突；合并记录无重复、按 HLC 排序 |
| P1 | 两站分别预留 4 kg 与 3 kg（> 5 kg） | `over_reservation` 冲突；两条预留都保留 |
| P2 | 两站租约重叠（含偏差界） | `double_ownership` 冲突；租约不删除 |
| P3 | 同一幂等键被两站的两个动作使用 | `duplicate_idempotency_key` 冲突；动作不被覆盖 |
| P4 | 同一动作在两站都转 `dispatched` | `double_dispatch` 冲突；状态不静默合并 |
| P5 | 连续两次交换（重复分区/重连） | 记录数不重复增长；冲突数稳定 |

## 3. 指标与判定

- 主指标：每个场景的冲突类别与数量与上表一致；无"静默"冲突（即冲突数 > 0 且被报告）。
- 次指标：合并记录数、重复记录数、预留/租约保留数。
- 若全部场景符合期望 → 模拟分区部分被支持；否则失败并修复。
- 全部运行（含失败）写入原始输出；**明确标注 simulated，非真实多节点**。

## 4. 局限

- 进程内模拟，不覆盖真实网络分区、认证、加密、时钟漂移与重启；
- 真实多节点复测（M12.6 的物理部分）需要外部网络环境，未完成前不宣称 M12 退出。
