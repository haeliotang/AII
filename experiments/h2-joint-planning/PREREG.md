## 1. 问题

在相同扰动轨迹与预算下，**联合规划**（结构候选 + 时间/状态感知 + 失败恢复 + 重规划）是否比三种规则/短视策略更能在截止前维持关键服务？

> **H2**：联合规划在截止成功率上优于任务优先级、带安全库存规则与短期资源优化基线。

## 2. 方法

| 方法 | 说明 |
| --- | --- |
| **A 联合规划** | `poie-plan::plan`（M8.1）+ 每次观测后 `replan`（M8.2）；结构候选、调度、失败资产有界恢复；所有动作经 SAP 校验路径 |
| B1 任务优先级 | 固定顺序处理目标，只在结构阻断时尝试修复，忽略截止（M8.3） |
| B2 安全库存规则 | 任务优先级 + 修复/路线所需资源必须高于安全库存阈值（M8.3） |
| B3 短期资源优化 | 每次选择最早可完成的目标，忽略截止与长期退化（M8.3） |

所有方法的输出都以相同 `Plan` 结构表示，并经 `validate_plan_through_sap`；SAP 校验失败视为该方法该场景的失败运行，不得静默跳过。

## 3. 场景与扰动

- 基础：Base-01 v0.2 结构模型 + 时间线（泵磨损、母线故障、昼夜能量、补给中断）。
- 规模：**24 个场景 = 16 开发 + 8 留出**；留出集在开发期间不查看（只在最终报告中评估）。
- 生成：固定种子 `poieweave-h2-2026-10-31`（SplitMix64）；参数从预定义集合抽取：
  - 泵失效时刻 ∈ {0, 2, 4, 6} h；母线失效时刻 ∈ {12, 16, 20} h；
  - 初始电池能量 ∈ {0.5, 1, 2} kWh；补给中断时刻 ∈ {6, 10, 14} h；
  - 目标：供水服务 + 车床恢复；截止 = 最早预测失效起点（显式 `prediction` 语义）。
- 扰动轨迹对所有方法**完全相同**（共同外生源）；不使用未来信息（策略只看到当前观测）。
- 每个场景允许最多 4 次重规划（新观测触发），预算一致。

## 4. 指标

主指标：
1. **截止成功率**：该场景全部目标在截止前完成的场景比例（按场景计，非按目标加权）。
2. 服务维持时长（截尾按 VEC §4.1，截尾时不报均值）。

次指标：
3. 恢复时间（未恢复按截尾报告）；4. 动作数（预算消耗）；5. 未达成原因分布；6. SAP 校验通过率（必须 100%）。
7. 失败/超时/不可行运行全部计入分母并分别报告。

## 5. 决策规则

在**留出集**上：
- 若 A 的截止成功率 ≥ 最佳基线 + 15 个百分点，且次指标不劣于最佳基线 → H2 被支持；
- 若仅主指标严格更优但差距 < 15pp → 部分支持（报告效应量与置信区间）；
- 若 A 不优于最佳基线 → H2 不被支持，按负结果发布。
- 任何方法出现 SAP 校验失败或未记录运行 → 该结果无效，先修正再报告。

## 6. 消融（M8.5）

在开发集上逐项移除：长期时域（仅下一个班次）、退化预测、能力依赖、重规划；每项消融在同一 24 场景与预算下运行，报告主/次指标变化。消融结果不参与 H2 主判定，但必须发布。

## 7. 公平性与复现

- 同一扰动轨迹、同一预算、同一截止定义、同一 SAP 校验路径；
- 所有方法使用相同种子与场景顺序；报告种子、代码提交、工具链、运行时间与全部运行（含失败）；
- 复现清单写入 `REPORT.md`；命令：`cargo run -p poie-h2-joint-planning -- ...`（运行器在运行前提交）。

## 8. 局限

- Base-01 v0.2 为合成场景，成本/时间参数未校准；
- 规划器是确定性贪心（ADR-0006），非最优；
- 作者相同、样本 24（留出 8），统计功效有限；外部配额（M3.3）仍未满足；
- 结论只适用于本模型与扰动集合。
